## Changes / 更新内容

- Windows 11 / WSL2: automatic host preparation and QR pairing, with a standalone PowerShell launcher included. Android can copy the Windows pairing command directly. Windows connects to WSL Linux, not a native PowerShell terminal.
- Pairing retains in-flight state across Activity recreation and tolerates up to 30 seconds of clock skew for the pinned ephemeral certificate; certificate pins and QR expiration remain enforced.
- SSH connection form: improved spacing, password/private-key selector, navigation actions and input contrast in light and dark modes.
- Existing signed releases can upgrade normally; local connections and settings are retained. Do not uninstall to upgrade.

- 新增 Windows 11 / WSL2 主机准备与扫码配对，提供独立 PowerShell 脚本；App 配对页可以直接复制 Windows 命令。
- 修复配对页面重建时的状态丢失，并处理电脑与手机小幅时钟偏差。
- 优化 SSH 连接表单的间距、认证方式切换、导航操作及亮暗色输入框对比度。

Windows PowerShell 5.1/7 CI, isolated Linux SSH/tmux and Android API 27 transport checks passed. Real Windows + WSL2 + phone end-to-end acceptance remains pending because no Windows device was available. No Maven package is published.
